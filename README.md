# Prajwal's Portfolio

Prajwal's Portfolio is a handcrafted cybersecurity showcase that highlights student SOC work, detection engineering experiments, and blog-worthy lab write-ups. The site is fully responsive and built with plain HTML, CSS, and a sprinkle of vanilla JavaScript.

## Highlights

- Glassmorphism-inspired UI with Space Grotesk & Poppins typography.
- Sections for foundational practice, certifications, resume timeline, portfolio pieces, blog posts, and contact channels.
- Mail-ready contact form with mailto fallbacks and clipboard copy utility.
- Lightweight interactions: sidebar toggle, portfolio filtering, testimonial modal, and animated cards.
- Ready for deployment on any static host (GitHub Pages, Netlify, Vercel, etc.).

## Getting Started

1. Clone the repository:

	```bash
	git clone https://github.com/your-username/prajwal-portfolio.git
	cd prajwal-portfolio
	```

2. Open `index.html` in your browser, or launch a local server:

	```bash
	# Using VS Code
	code .
	# Then run the Live Server extension
	```

3. Update content inside `index.html`, visuals in `assets/images/`, and styles in `assets/css/style.css` as needed.

## Deployment

- **GitHub Pages:** Push to a repository and enable Pages on the `main` branch.
- **Netlify/Vercel:** Drag-and-drop the folder or connect the repo for automatic builds.
- **Custom hosting:** Upload the root folder to any static file server.
